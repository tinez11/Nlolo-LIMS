## Design Specificity Verdict

**Authored in its judgment, generic in its form.** The shell is a self-declared Attio/Squarespace CRM copy (PLAN.md section 2). Specificity lives in judgment: domain-keyed six-bucket status vocabulary, em-dash-not-Unknown, the unrecognised-literal ring, refusal of trend arrows, hand-built DD/MM/YYYY picker, the Event-journal disclaimer. But it is an ethic, not a visual language. GatePanel, called in DESIGN.md "the component that makes this an insurance console rather than a CRUD app", ships on ONE screen out of thirty-four; its promised sibling issueGates was never written.

**Deterministic scan.** detect.mjs --json frontend/src returned exit 0 and an empty array. Zero findings across 200 files. index.html returned 1 finding: overused-font (Inter), ruled a non-issue for an Operate surface. Caveat: HTML parser modules unresolvable, tool self-reported degraded, findings an undercount.

**Overlays.** Injection succeeded on authenticated /staff/policies: 10 anti-patterns light, 31 dark. Real: low-contrast 3.4-3.5:1 on five sidebar group captions and the stat-card hint; cramped-padding on three sidebar count pills. Two false positives disproved: gradient-text (zero background-clip:text elements in the document) and ai-color-palette "cyan neon" on 30 dark Active badges (measured 8.46:1, reads as muted teal).

## Overall Impression

The most intellectually honest front-end codebase reviewed in a while, and not yet a designed product. Every hard call about what NOT to render has been made correctly and written down. Almost no call about how the person doing the work experiences it has been made at all. The biggest opportunity is not a redesign: the product already contains the parts that would fix it and is not using them.

## What's Working

1. **StatusBadge + lib/status.ts, the unrecognised-literal ring.** An unseen status renders in its fallback bucket PLUS an inset ring, a trailing question mark, and a title naming the literal. Makes the system's blind spot a visible event on the glass. All six buckets clear contrast in both themes (6.01-8.83:1).
2. **components/states.tsx and the stale-data banner.** Per-kind copy, no false retry on 403/501, never promises absence on 404, select-all traceId, keeps stale rows behind a warning strip rather than replacing real data with an error page.
3. **Dark mode is genuinely finished.** Verified in capture: no untokenised patch, no theme-blind surface, no unreadable text.

## Priority Issues

### [P0] Right-aligned numeric columns are not actually right-aligned

DataTable.tsx:104-105 puts text-right on the td, but wraps content in a div with class "flex h-11 items-center". text-align does not position a flex item; default justify-content flex-start does. The th right-aligns, the td does not. Measured: the "Sum assured" header right edge sits about 103px right of its values on /staff/policies; "Posted" about 140px on /staff/gl-postings. Hidden on policies only because every value is the same character length. This is the North Star failing its own test: the Tabular Rule and global tabular-nums exist so figures compare vertically, and the flex wrapper discards the alignment that makes them worth having.

FIX: apply justify-end to the inner div (and the first-cell button) when column.align is 'right'.

## Questions to Consider

1. GatePanel is called the component that makes this an insurance console rather than a CRUD app, and renders on one screen out of thirty-four. What if every mutating surface had to declare its preconditions before rendering a submit button?
2. The console renders only what the platform can prove, but does it render everything the platform CAN prove? PartyName works and is used once. GET /agents exists and Agent of record is still a UUID paste field.
3. Success is currently defined as "the form disappeared." What would a receipt look like?
4. 12px is the workhorse: 226 uses against 98 at 14px. DESIGN.md names 14px as body and 12px as label; the code says the opposite happened. Who decided the default reading size for an eight-hour job is 12 pixels?
5. The sidebar spends seven group captions on eleven links, four of them captioning a single item. Is that IA designed for the console that exists, or for the four undesigned contexts that might fill it?
